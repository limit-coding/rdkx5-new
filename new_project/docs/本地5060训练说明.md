# 本地 RTX 5060 训练说明

更新时间：2026-05-12

## 环境策略

本机训练只使用 Conda 隔离环境，不依赖系统 Python，也不需要项目内 `.venv`。

环境名：

```powershell
drone-yolo11
```

核心版本：

```text
Python 3.11.15
torch 2.11.0+cu128
torchvision 0.26.0+cu128
Ultralytics 8.4.48
GPU: NVIDIA GeForce RTX 5060 Laptop GPU
CUDA runtime: 12.8
```

检查命令：

```powershell
cd "D:\yolo training\BUPT--rdkx5\ai_training"
.\scripts\windows\check_env.ps1
```

如需从零重建 Conda 训练环境：

```powershell
cd "D:\yolo training\BUPT--rdkx5\ai_training"
.\scripts\windows\setup_conda.ps1
```

## 数据来源

CIFAR-100 官方页面：

```text
https://www.cs.toronto.edu/~kriz/cifar.html
```

直接下载包：

```text
https://www.cs.toronto.edu/~kriz/cifar-100-python.tar.gz
```

本次训练把 CIFAR-100 用于两件事：

1. `cifar100_target_cls`：图片靶中心分类，100 类。
2. `micro_drone_det`：合成 YOLO 检测集，其中 `picture_target` 使用 CIFAR 图块，其他比赛目标用规则图形生成，用来跑通检测训练链路。

合成检测集不是最终实拍比赛数据，后续有实拍标注数据时直接替换 `datasets/micro_drone_det/images` 和 `labels` 即可。

## RDK X5 `.bin` 转换准备

当前 PC 已经准备好 CIFAR-100 分类模型的 RDK 转换包：

```text
ai_training/rdk_convert/cifar100_cls/
  best.onnx
  cifar100_cls_bayese_224x224_nv12.yaml
  calibration_images/
```

准备命令：

```powershell
cd "D:\yolo training\BUPT--rdkx5\ai_training"
.\scripts\windows\prepare_rdk_cls_convert.ps1
```

实际转换命令：

```powershell
.\scripts\windows\run_rdk_cls_convert_docker.ps1
```

这一步需要 Docker / RDK ToolChain。当前这台 Windows 机器的普通用户会话无法完成 Docker 安装，因为启用 WSL 和虚拟机平台需要管理员权限：

```text
Enable-WindowsOptionalFeature: The requested operation requires elevation.
Docker Desktop installer failed with exit code 4294967291.
```

用管理员权限安装 Docker Desktop 并重启后，再运行上面的转换脚本。成功后脚本会复制模型到：

```text
ros2_ws/src/camera/resource/cifar100_cls.bin
```

板端分类节点已经准备好：

```text
ros2_ws/src/camera/camera/cifar100_cls_enable.py
ros2_ws/src/camera/resource/cifar100_names.txt
```

构建后运行：

```bash
ros2 run camera cifar100_cls_enable
```

它会加载：

```text
/home/sunrise/ros2/diansai/ws/src/camera/resource/cifar100_cls.bin
```

并发布：

```text
/pic_cls_name   top1 名称和置信度
/pic_cls_top5   top5 类别 id 和分数
```
