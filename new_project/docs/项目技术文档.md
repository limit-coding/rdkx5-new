# 2025-RDKx5-CODING 项目技术文档

> 基于 ROS2 + RDK X5 的无人机自主巡检与动物识别系统

---

## 一、项目概述

本项目是一套运行在 **RDK X5 机载电脑**上的 **ROS2 无人机自主飞行系统**，用于电子设计竞赛。核心任务是：

1. 无人机起飞后，通过蓝牙从地面站接收 **3 个禁飞区坐标**
2. 在一个 **9×7 的栅格地图**（A1-A9 × B1-B7）上进行 **A\* 路径规划**，生成遍历所有可通行格子的路径
3. 沿路径飞行，在每个格子上空 **悬停拍照**，使用 **YOLO11 + BPU 加速**识别 5 种动物（孔雀、狼、猴子、大象、老虎）
4. 将识别结果通过 **蓝牙**发送给地面站
5. 遍历完成后 **45度斜降落**回到起飞点

## 三、模块详解

### 3.1 地图模块 (`main/map/map.py`)

**功能**：定义 9×7 的二维栅格地图。

```
地图坐标系：
  x: 0~8 (对应 A1~A9，行方向)
  y: 0~6 (对应 B1~B7，列方向)

  map[x][y] = 0 表示可通行
  map[x][y] = 1 表示禁飞区（障碍物）
```

- `self.map`：9×7 的二维列表，初始全部为 0（可通行）
- `self.blocks`：存储禁飞区坐标的列表，格式为 `[(x1,y1), (x2,y2), (x3,y3)]`
- `x_char` / `y_char`：行列索引到人类可读标签（A1~A9, B1~B7）的映射

**物理坐标换算**：每个格子对应 0.5m，即 `实际x = y索引 × 0.5`, `实际y = (8 - x索引) × 0.5`

### 3.2 A\* 路径规划 (`main/planner/a_star.py`)

**功能**：在栅格地图上计算两点间最短路径（四方向移动）。

**核心逻辑**：
1. 使用 **曼哈顿距离** 作为启发函数
2. 维护 **优先队列**（开放列表）和 **集合**（关闭列表）
3. 每次取 f 值最小的节点扩展，直到到达终点
4. 回溯父节点链得到完整路径

**输入**：`a_star(grid, start, end)` — 栅格地图、起点坐标元组、终点坐标元组
**输出**：从起点到终点的坐标列表 `[(x1,y1), (x2,y2), ...]`，无路径时返回 `None`

### 3.3 路径规划器 (`main/planner/planner.py`)

**功能**：在含障碍物的地图上生成遍历所有可通行格子的完整路径 + 返回降落路径。

#### `plan_stop()` 方法 — 主入口（main_stop.py 使用）

**核心思路：弓字形遍历 + A\* 绕障**

根据 3 个禁飞区的排列方式决定遍历方向：

```
情况1：禁飞区在同一列（blocks[0].y == blocks[1].y）
  → 按列优先遍历：y 从 0 到 6，每列内 x 交替正序/逆序（蛇形走位）

情况2：禁飞区不在同一列
  → 按行优先遍历：x 从 8 到 0，每行内 y 交替正序/逆序
```

对每个格子：
- **可通行且未被阻断**：直接加入路径，标记为 `(x, y, 1)`（1 表示需要停留拍照）
- **可通行但之前被障碍物阻断**：用 A\* 计算绕行路径，中间点标记为 `(x, y, 0)`（0 表示不停留）
- **禁飞区**：跳过，标记 `blocked = True`

#### `plan_landing()` 方法 — 降落路径

检查从最后一个遍历点到起飞点 `(8, 0)` 的路径是否有障碍物：
- **有障碍**：先飞到 `(8, lastY)` 再飞到 `(8, 0)`（沿边界绕行）
- **无障碍**：先飞到 `(lastX, 0)` 再飞到 `(8, 0)`（直接切回）

#### 路径后处理 (`ProcessPath()`，在 main_stop.py 中)

1. **坐标转换**：将栅格坐标转为实际飞行坐标（米），存入 `way_point`
2. **拐点提取**：遍历路径找出方向变化的点（`corner_index`），用于状态机判断
3. **终点特殊处理**：降落段最后一个 waypoint 设为离地面的绝对坐标 `(1.2, 0, 0)` 或 `(0, 1.2, 0)`

### 3.4 控制器 (`main/controller/controller.py`)

**功能**：接收传感器数据、计算位置误差、发布控制指令。

#### 状态枚举 (`state`)

| 状态 | 值 | 含义 |
|------|----|------|
| `Takeoff` | 0 | 起飞阶段 |
| `Stop` | 1 | 悬停拍照（到达目标点等待） |
| `Cruise` | 2 | 巡航（匀速飞过不需停留的点） |
| `MoveTo` | 3 | 移动到下一个目标点 |
| `Landing` | 4 | 降落阶段 |
| `Finish` | 5 | 任务完成 |

#### 动力学数据 (`dynamics` 类)

```python
current_pose  = {'x', 'y', 'z', 'yaw'}   # 当前位姿（来自SLAM+高度计）
target_pose   = {'x', 'y', 'z', 'yaw'}   # 目标位姿
initial_pose  = {'x', 'y', 'z', 'yaw'}   # 初始位姿（解锁时记录，作为原点）
position_error = [ex, ey, ez, eyaw]       # 位置误差
target_speed  = {'x', 'y', 'z'}          # 目标速度
```

#### 关键方法

- **`calculate_position_error()`**：计算 odom 坐标系下的位置误差，然后通过 yaw 旋转矩阵转换到 **机体坐标系**（重要！飞控接收的是机体坐标系误差）
- **`publish_position_error(error)`**：将位置误差通过 `/pos_pub` 发布给串口→飞控
- **`publish_speed(speed)`**：将速度指令通过 `/pos_pub` 发布给串口→飞控
- **`to_point_error(error)`**：计算 XY 平面的欧氏距离误差
- **`quaternion_to_euler()`**：四元数转欧拉角（仅提取 yaw）

#### 关键参数

```python
takeoff_height = 1.2          # 起飞/巡航高度 (m)
position_tolerance_xy = 0.1   # XY方向到点容差 (m)
position_tolerance_z = 0.07   # Z方向到点容差 (m)
```

### 3.5 主控状态机 (`main/main/main_stop.py`)

**这是整个系统的核心**，实现完整的任务流程状态机。

#### 初始化流程

```
1. 创建 Pathplanner、Controller 实例
2. 设置初始状态为 Takeoff
3. 开启 GPIO 37 (激光笔)
4. 启动 ROS2 多线程执行器
5. 后台线程调用 run()：
   - 发布 /start 信号
   - 阻塞等待 blocks_event（蓝牙收到禁飞区后触发）
   - 创建 main_fsm 定时器 (100ms 周期)
```

#### 状态机 `main_fsm()` 完整流转

```
                    ┌─────────┐
                    │ Takeoff │ 起飞到 1.2m
                    └────┬────┘
                         │ z误差 < 0.07m
                    ┌────▼────┐
              ┌────►│ MoveTo  │ 飞向下一个航点
              │     └────┬────┘
              │          │ XY误差 < 0.1m
              │     ┌────▼────┐
              │  是  │该点需要  │ path[i][2] == 1?
              │◄─否──│ 停留？  │
              │     └────┬────┘
              │          │ 是
              │     ┌────▼────┐
              │     │  Stop   │ 悬停0.5秒拍照识别
              │     └────┬────┘
              │          │ 超时后
              │     ┌────▼────────────────┐
              │     │ 发布pic_enable=0    │
              │     │ 统计动物众数         │
              │     │ movepoint++         │
              │     │ 切回 MoveTo         │
              └─────┴────┬────────────────┘
                         │ movepoint >= 路径长度
                    ┌────▼────┐
                    │ Landing │ 45度斜降落
                    └────┬────┘
                         │ z < 0.07m
                    ┌────▼────┐
                    │ Finish  │ 发布上锁指令
                    └─────────┘
```

#### Stop 状态详解

当无人机到达一个需要拍照的格子（`path[i][2] == 1`）时：
1. 切换状态为 `Stop`
2. 发布 `pic_enable=1`，启动摄像头推理
3. 启动 `wait_timer`（0.5秒定时器）
4. 清空 `animals` 列表，开始收集检测结果
5. 0.5秒后 `wait_timeout` 触发：
   - 发布 `pic_enable=0`，停止推理
   - 调用 `calculate_reliable_counts()`，对每种动物取**众数**作为最可信数量
   - 发布动物计数到 `/animals`
   - `movepoint++`，切回 `MoveTo`

#### 降落逻辑详解

降落采用 **45度斜降** 策略，目标速度恒定为 30 单位（speed_component = 30 × sin(45°) ≈ 21.2）：
- 根据最后一段路径方向（x 方向 or y 方向），分别计算水平和垂直速度分量
- 维持水平/垂直位移比例一致，实现 45° 斜线轨迹
- 接近地面时（z < 0.1m）线性减速
- z < 0.07m 时判定降落完成，发布上锁指令

### 3.6 视觉检测 (`camera/camera/animal_detect_enable.py`)

**功能**：使用 YOLO11 模型在 RDK X5 的 BPU 上进行 5 类动物检测。

#### 模型配置

```python
model_path = "/home/sunrise/ros2/diansai/ws/src/camera/resource/diansai0801.bin"
conf_thres = 0.3    # 置信度阈值
iou_thres = 0.5     # NMS IOU阈值
classes = 5          # 5类：peacock, wolf, monkey, elephant, tiger
input_size = 640×640 # 模型输入尺寸
```

#### 推理流程

```
摄像头(640×480,NV12) → 旋转180° → 中心裁剪(480×480)
→ resize到640×640 → BGR转NV12 → BPU推理
→ 三尺度特征图后处理(DFL+dist2bbox) → NMS
→ 发布 /pic_cnt [孔雀数, 狼数, 猴数, 象数, 虎数]
```

#### 使能控制

- 订阅 `/pic_enable` 话题：`1` 开始推理，`0` 停止推理
- 未使能时 `sleep(0.01)` 避免空转

### 3.7 串口通信 (`communication/communication/uart.py`)

**功能**：RDK X5 ↔ 飞控 的串口通信桥梁。

#### 通信协议

| 方向 | 帧格式 | 说明 |
|------|--------|------|
| 上位机→飞控 | `AA FF 80 10 [4×float32] [checksum]` | 发送位置误差 (x,y,z,yaw) |
| 上位机→飞控 | `AA FF 83 06 [3×int16] [checksum]` | 发送速度指令 (x,y,z) |
| 上位机→飞控 | `AA FF 81 [len] [ascii] [checksum]` | 发送字符串指令（如 "lock"） |
| 飞控→上位机 | `AA FF 04 [4B] [checksum]` | 高度数据 (int32, cm) |
| 飞控→上位机 | `AA FF 06 [6B] [checksum]` | 解锁字符串 ("unlock") |
| 飞控→上位机 | `AA FF 12 [18B] [checksum]` | IMU 数据 (加速度+陀螺仪+欧拉角) |
| 飞控→上位机 | `AA FF 01 [1B] [checksum]` | 程序选择 |

串口配置：`/dev/ttyS1`，115200 波特率

### 3.8 蓝牙通信 (`communication/communication/bluetooth.py`)

**功能**：RDK X5 ↔ 地面站的蓝牙串口通信。

#### 接收流程

```
接收蓝牙数据 → 帧解析(AA FF 02 [2B]) → 提取禁飞区坐标(x,y)
→ 累计3个后 → 调用 /pathplan_srv 服务 → 获取路径
→ 定时(0.5s)逐个发送航点给地面站
```

#### 发送流程

| 功能码 | 数据 | 说明 |
|--------|------|------|
| `0x00` | 2B (x,y) | 发送航点坐标 |
| `0x01` | 7B (pos+5×count) | 发送动物计数结果 |
| `0x02` | 无数据 | 发送启动心跳 |

蓝牙串口配置：`/dev/ttyS7`，57600 波特率

### 3.9 TF 坐标变换 (`tf/tf/tf_publisher.py`)

**功能**：将 SLAM 里程计和目标点发布为 ROS2 TF 变换，用于 RViz 可视化。

- `map → base_link`：无人机当前位姿
- `map → target_point`：当前目标点位姿
- 支持运行时参数录制位姿数据并用 matplotlib 绘图

## 四、完整数据流时序

```
[启动] GPIO37=HIGH (激光笔)
   │
   ▼
[main_ctrl] 发布 /start → [bluetooth] 开始心跳
   │
   ▼
[蓝牙地面站] ──3个禁飞区坐标──► [bluetooth]
   │
   ▼
[bluetooth] 调用 /pathplan_srv ──► [main_ctrl.pathplan_callback]
   │                                     │
   │                               设置map障碍 → plan_stop() → ProcessPath()
   │                               blocks_event.set()
   │                                     │
   │◄── 返回路径(拐点坐标列表) ──────────┘
   │
   ▼
[bluetooth] 定时0.5s发送航点给地面站
   │
   ▼
[main_ctrl.run()] blocks_event 解除阻塞
   │
   ▼ 创建 main_fsm 定时器 (100ms)
   │
   ▼
[Takeoff] → 发布位置误差到 /pos_pub
   │         [uart] 转发串口帧给飞控
   │         飞控内部PID控制起飞
   │
   ▼ z到达1.2m
[MoveTo] → 设置下一航点 → 发布位置误差
   │
   ▼ 到达航点 且 需要拍照
[Stop] → 发布 pic_enable=1
   │      [camera] 开始推理 → 发布 /pic_cnt
   │      [main_ctrl] 收集动物计数
   │
   ▼ 0.5秒后
   发布 pic_enable=0 → 统计众数 → 发布 /animals
   [bluetooth] 转发动物数据给地面站
   │
   ▼ movepoint++ → 回到 MoveTo
   ... (循环直到遍历完成)
   │
   ▼
[Landing] → 45度斜降 → 速度指令 → [uart] → 飞控
   │
   ▼ z < 0.07m
[Finish] → 发布 /lock → [uart] → 飞控上锁
         → GPIO37=LOW (关闭激光笔)
```

## 六、如何修改功能

### 6.1 调整飞行高度

修改 `main/controller/controller.py` 第 55 行：

```python
self.takeoff_height = 1.2  # 改为你想要的高度(米)
```

### 6.2 调整到点精度

修改 `main/controller/controller.py` 第 56-57 行：

```python
self.position_tolerance_xy = 0.1   # XY方向容差(米)，越小越精确但越慢
self.position_tolerance_z = 0.07   # Z方向容差(米)
```

### 6.3 调整拍照悬停时间

修改 `main/main/main_stop.py` 第 48 行的 `wait_timer` 周期：

```python
self.wait_timer = self.create_timer(0.5, self.wait_timeout)  # 0.5秒，可改大以获得更多帧
```

悬停时间越长，收集的检测帧越多，众数统计越准确，但总用时增加。


4. 如果类别数变化，修改第 319 行的类别数和第 268 行的名称列表：

```python
model = YOLO11_Detect(model_path, conf_thres, iou_thres, 新类别数)
coco_names = ["类别1", "类别2", ...]
```

### 6.5 修改检测阈值

修改 `camera/camera/animal_detect_enable.py` 第 316-317 行：
