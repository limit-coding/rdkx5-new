# 二维码识别第一版使用指南

适用前提：USB 摄像头已经能通过 `hobot_usb_cam` 发布 `/image`，图像格式为 JPEG 压缩图像。

## 1. 第一版方案

当前实现基于 OpenCV `QRCodeDetector`，不需要训练模型。

第一版默认要求二维码必须成功解码出文本；如果 OpenCV 只检测到疑似二维码轮廓但文本为空，会按未识别处理，避免飞控收到假目标。

图像链路：

```text
USB 摄像头
  -> hobot_usb_cam
  -> /image
  -> camera/qr_show
  -> /qr_code/text
  -> /qr_code/offset
  -> /qr_code/result
```

## 2. 启动 USB 摄像头

在机载电脑上执行：

```bash
source /opt/ros/humble/setup.bash
source /opt/tros/humble/setup.bash

ros2 launch hobot_usb_cam hobot_usb_cam.launch.py \
  usb_video_device:=/dev/video0 \
  usb_image_width:=1280 \
  usb_image_height:=720 \
  usb_pixel_format:=mjpeg \
  usb_framerate:=30
```

## 3. 启动二维码识别节点

另开一个终端，在项目工作空间中执行：

```bash
source /opt/ros/humble/setup.bash
source /opt/tros/humble/setup.bash
source install/setup.bash

ros2 run camera qr_show
```

如果图像话题不是 `/image`，可以改参数：

```bash
ros2 run camera qr_show --ros-args -p image_topic:=/image
```

如果调试时想观察“疑似二维码但未解码出文本”的轮廓，可以临时允许空文本：

```bash
ros2 run camera qr_show --ros-args -p allow_empty:=true
```

## 4. 输出话题

### `/qr_code/text`

类型：`std_msgs/String`

内容：二维码文本。

查看：

```bash
ros2 topic echo /qr_code/text
```

### `/qr_code/offset`

类型：`std_msgs/Int32MultiArray`

格式：

```text
[found, cx, cy, dx, dy, area]
```

含义：

- `found`: 是否识别到二维码，`1` 表示识别到，`0` 表示未识别到。
- `cx`: 二维码中心点 x 坐标。
- `cy`: 二维码中心点 y 坐标。
- `dx`: 二维码中心相对画面中心的 x 偏差，右正左负。
- `dy`: 二维码中心相对画面中心的 y 偏差，下正上负。
- `area`: 二维码四边形面积，粗略反映二维码在画面中的大小。

查看：

```bash
ros2 topic echo /qr_code/offset
```

飞控/导航第一版可以先只用：

```text
dx, dy, area
```

### `/qr_code/result`

类型：`std_msgs/String`

内容：JSON 字符串，包含文本、中心、偏差、面积和四个角点。

查看：

```bash
ros2 topic echo /qr_code/result
```

## 5. 不走 ROS 的快速测试

如果只是想确认摄像头画面里能不能识别二维码，可以直接读 `/dev/video0`：

```bash
source install/setup.bash

ros2 run camera qr_test \
  --device /dev/video0 \
  --width 1280 \
  --height 720 \
  --fps 30
```

默认会过滤文本为空的误检。调试轮廓时可加：

```bash
--allow-empty
```

看到二维码时会输出：

```text
QR text='...' center=(x,y) offset=(dx,dy) area=...
```

也可以对单张图片测试：

```bash
ros2 run camera qr_test \
  --image /tmp/qr.jpg \
  --output /tmp/qr_annotated.jpg
```

## 6. 调试建议

1. 先用大二维码测试，确保画面中二维码边长大于 100 像素。
2. 摄像头先用 `1280x720 MJPEG 30fps`。
3. 保持二维码平整，避免反光和过斜角度。
4. 飞控动作不要基于单帧结果，建议连续 3 到 5 帧识别一致再触发任务。
5. 如果飞行时识别不稳，优先检查运动模糊、曝光、二维码尺寸和摄像头固定。
